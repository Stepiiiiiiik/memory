# Memory Match 🎴

Десктопная игра «Найди парочки» (memory) на **Kotlin + Jetpack Compose**
(Compose Multiplatform for Desktop, JVM). Работает на Windows, macOS и Linux.

Поле до **80 карточек** (40 пар), плавная анимация переворота, таймер,
счётчик ходов и найденных пар, светлая и тёмная темы (следует теме ОС).

Вместо картинок-иконок используются **эмодзи** — они рисуются цветным
системным шрифтом, не раздувают приложение и выглядят аккуратно.

## Что внутри

- **Три режима:**
  - «Один игрок» — на время и количество ходов;
  - «Два игрока» (за одним компьютером) — по очереди, угадал пару — ходишь
    снова, промахнулся — ход переходит; в конце победитель (или ничья) и счёт;
  - **«Сетевая игра»** — мультиплеер по локальной сети (см. ниже).
- **3 уровня сложности:** Разминка (24 карты), Классика (48), Марафон (**80**).

## Сетевая игра (по локальной сети)

1. На главном экране нажми **🌐 Сетевая игра** и введи никнейм.
2. Откроется лобби со списком игроков, которые тоже в сети и ждут игру
   (список обновляется автоматически).
3. Нажми **Пригласить** напротив нужного игрока и дождись ответа — либо
   прими входящее приглашение, когда оно придёт тебе.
4. После принятия у обоих запускается одинаковое поле, ходы — по очереди
   (пригласивший ходит первым). Активный игрок подсвечен, сверху — «Ваш ход».

В лобби под вашим ником показан **ваш адрес** (`IP:порт`) — удобно для проверки,
что два экземпляра различаются, и для настройки файрвола.

**Как это устроено:** без внешнего сервера. Обнаружение игроков — UDP-multicast
(группа `239.255.42.99`, порт `45777`), приглашения и синхронизация ходов — прямое
TCP-соединение между двумя клиентами (порт из диапазона **45780–45799**). Оба
запускают идентичную детерминированную логику над одной перемешанной колодой,
поэтому поля совпадают. Если соперник оказался на этом же компьютере (тест в
двух окнах), подключение идёт через `127.0.0.1` — это обходит локальный файрвол.

**Ограничения и требования:**
- Оба игрока должны быть в **одной локальной сети** (Wi-Fi/LAN). Для проверки
  можно запустить **два окна приложения на одном компьютере** — они увидят
  друг друга и соединятся через loopback.
- Для игры **между разными машинами** нужно разрешить в **файрволе**:
  UDP-порт `45777` (обнаружение) и входящие TCP-подключения на порты
  `45780–45799`. Примеры:
  - Linux (ufw): `sudo ufw allow 45777/udp && sudo ufw allow 45780:45799/tcp`
  - Windows: разрешить приложению Java доступ в «частной» сети, когда появится
    запрос файрвола.
- Если приглашение падает с ошибкой «Не удалось связаться…» — в тексте указан
  адрес и причина; чаще всего это закрытый порт в файрволе или изоляция клиентов
  в сети (гостевой Wi-Fi часто блокирует связь между устройствами).
- Интернет-матчмейкинг между разными сетями здесь не поддерживается (нужен
  отдельный сервер) — это возможное дальнейшее расширение.
- **Дизайн** в стиле Material 3: тёплая «бумажная» палитра, тёмно-бирюзовый
  с терракотовым акцентом — без штампованных неоновых градиентов.
- Адаптивная сетка карточек (число столбцов подстраивается под размер окна),
  поле прокручивается, когда карт много.

## Структура

```
src/main/kotlin/com/example/memory/
├── Main.kt                    # точка входа: окно приложения
├── model/
│   ├── Card.kt                # модель карточки
│   └── EmojiDeck.kt           # набор из 40 эмодзи
├── game/
│   ├── Difficulty.kt          # уровни сложности
│   └── GameController.kt      # игровая логика и состояние (локал + онлайн)
├── net/                       # сетевой слой
│   ├── PeerInfo.kt            # найденный в сети игрок
│   ├── Protocol.kt            # формат сообщений + кодирование колоды
│   ├── Discovery.kt           # обнаружение по UDP-multicast
│   ├── GameConnection.kt      # TCP-канал (чтение/запись строк)
│   └── NetworkManager.kt      # лобби, приглашения, синхронизация
└── ui/
    ├── MemoryApp.kt           # навигация и связывание игры с сетью
    ├── HomeScreen.kt          # меню: режим, сложность, вход в сеть
    ├── NicknameScreen.kt      # ввод никнейма
    ├── LobbyScreen.kt         # список игроков, приглашения
    ├── GameScreen.kt          # поле, панель статистики, экран результата
    ├── MemoryCard.kt          # карточка с анимацией переворота
    └── theme/                 # цвета и тема
```

## Требования

- **JDK 17** или новее (например, [Temurin](https://adoptium.net/)).
- Выход в интернет при первой сборке (Gradle докачает зависимости Compose).

## Запуск

> В репозитории нет бинарного файла `gradle-wrapper.jar` (его нельзя хранить
> как текст), поэтому Gradle Wrapper нужно один раз сгенерировать — либо
> запускать через установленный Gradle, либо открыть проект в IDE.

### Вариант A — установлен Gradle 8.x

```bash
cd memory
gradle wrapper --gradle-version 8.9   # один раз: создаст ./gradlew и wrapper.jar
./gradlew run                          # запустить приложение
```

### Вариант B — через IntelliJ IDEA (или Android Studio)

1. **File → Open** → выбери папку проекта (`memory`). IDE сама подтянет Gradle.
2. В панели Gradle открой задачу **Tasks → compose desktop → run** и запусти,
   либо запусти `fun main()` в `Main.kt` кнопкой ▶.

### Вариант C — сразу через Gradle без wrapper

```bash
cd memory
gradle run
```

## Сборка нативного установщика

Чтобы получить дистрибутив под текущую ОС (`.msi` / `.dmg` / `.deb`):

```bash
./gradlew packageDistributionForCurrentOS
# результат появится в build/compose/binaries/main/
```

Для portable-запуска без установщика подойдёт `./gradlew createDistributable`
(каталог с исполняемым файлом в `build/compose/binaries/main/app/`).

## Как играть

1. Выбери режим (**Один игрок** / **Два игрока**) и сложность, нажми **Играть**.
2. Открывай по две карточки. Совпали — остаются открытыми; нет —
   через мгновение закрываются.
3. **Соло:** открой все пары за меньшее время и число ходов. 🎉
   **На двоих:** набери больше пар, чем соперник. Угадал — ходишь снова;
   промахнулся — очередь переходит. В конце — экран с результатом.
